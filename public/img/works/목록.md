# Works 웹 파일 목록

- `thumb` = 카드 썸네일 · `gallery/` = 상세창 그림 · `process/` = 만든 과정 자료 · `ba-before/after` = 전후 비교 · `card/` = 카드 안 작은 그림
- 원본 위치 기준: `작업물/` 폴더
- 그림책 〈꿈〉 24쪽은 e북용으로 `img/book/` 에 따로 있음
